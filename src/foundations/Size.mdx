# Size

**In Figma:** two of them so far, the control heights 24 and 28 (the `Tokens` collection's variables `1:127` and
`1:129`, which the pull can't read off the drawing yet). The rest are **Not in Figma**: all of them are written by hand
in `tokens/size.tokens.json` (DTCG `dimension`, each with its Figma id where it has one). `npm run tokens:build` merges
them with the Figma tokens into `src/tokens.css`; `npm run tokens:pull` rewrites only the Figma files, so it never
wipes them. When the pull reads Figma's variables, these move there.

They are the sizes the components already draw, three kinds: icons, control heights and avatars. Each token is named
by its value in px. A width or height takes a size token wherever the box is an icon, a control or an avatar:

```css
.gv-icon-button { width: var(--gv-size-control-28); height: var(--gv-size-control-28); }
.gv-icon-button > svg { width: var(--gv-size-icon-16); height: var(--gv-size-icon-16); }
```

What stays a number: one-off geometry (a popover's or modal's width, a chart's bars, the phone preview's frame,
a progress track) and strokes. A border, a divider or a ring is 1, 1.5, 2 or 3 px wide: Figma binds stroke
weights to two variables, `--gv-border-width-1` and `--gv-border-width-2` (Focus and states). Gaps and paddings are
**Spacing**, not Size.

## Choosing a size

- **An icon in a button (a 24 one too), menu item, option, card or field**: `icon-16`. In a dense row or a
  disclosure: `icon-14`. In the side nav or a toast: `icon-18`. On its own with room around it: `icon-20` or
  `icon-24`.
- **A field or a button people use often**: `control-36`. A secondary, compact one: `control-32`. An icon button:
  `control-28` (`control-24` for a dismiss × inside a banner or toast).
- **A list, menu or tree row**: at least `control-32`, so every row is as easy to hit as a small button.
