# Typography

**In Figma:** the nine text styles on the Foundations page's Typography frame, each binding its size, line height and
weight to the `Tokens` collection's `font/` variables (`font/size-13`, `font/line-height-20`, `font/weight-medium`).

Nine roles on the 12 · 13 · 14 · 16 · 20 · 28 scale, Regular and Medium only: hierarchy comes from size steps and grey
versus black, not from extra weights. One rule sets them:

```css
.gv-row__title { font: var(--gv-type-ui-strong); }
```

To make a role's text medium without changing its size, override the weight with the font primitive, never a number:

```css
.gv-row__count { font: var(--gv-type-ui); font-weight: var(--gv-font-weight-medium); }
```

Letter spacing is set once, `--gv-font-tracking` (0) on `:root`, and every element inherits it: no role tracks its own.

## Which token for which job

Set text with one of the nine roles below (`font: var(--gv-type-ui)`), never with the size, line height and weight primitives one by
one.

| The job | Role |
|---|---|
| Buttons, the current breadcrumb, a selected segment, a row's title | `--gv-type-ui-strong` |
| The control text: list rows, table cells, menu options, breadcrumbs | `--gv-type-ui` |
| Reading text: descriptions, banners, a metric's label | `--gv-type-body` |
| Emphasised reading text: an alert dialog's title | `--gv-type-body-strong` |
| Panel, modal and dashboard card titles | `--gv-type-title` |
| Captions and meta: To review, Required, rail labels | `--gv-type-small` |
| Pills, a phase name, a sorted column header | `--gv-type-small-strong` |
| Big numbers in KPI tiles and stat rows | `--gv-type-stat` |
| Small number tiles, counts in rows | `--gv-type-stat-small` |
