# Typography

**In Figma:** the nine text styles on the Foundations page's Typography frame, each binding its size, line height and
weight to the `Tokens` collection's `font/` variables (`font/size-13`, `font/line-height-20`, `font/weight-medium`).

Nine interface roles on the 12 · 13 · 14 · 16 · 20 · 28 scale, and four document roles (below), Regular and Medium
only: hierarchy comes from size steps and grey versus black, not from extra weights. One rule sets them:

```css
.gv-row__title { font: var(--gv-type-ui-strong); }
```

To make a role's text medium without changing its size, override the weight with the font primitive, never a number:

```css
.gv-row__count { font: var(--gv-type-ui); font-weight: var(--gv-font-weight-medium); }
```

Letter spacing is set once, `--gv-font-tracking` (0) on `:root`, and every element inherits it: no role tracks its own.

## Which token for which job

Set text with one of the nine roles below (`font: var(--gv-type-ui)`), never with the size, line height and weight primitives one by
one.

## Document roles

**Not in Figma.** The type of a document people read or print on a sheet: a report's title page, its section headings,
its lead lines and its paragraphs (Components/Layout & containers/Page stage, Figure, Quote). Named for what the text
is in a document, never for the screen that shows it.

They have a family of their own, `--gv-font-family-document`, which is the interface's family by default. **Themable
per platform:** a platform's theme sets it (or a role) once, at `:root`, and its documents take its face while the
back office keeps Public Sans. Set it at `:root`, not on a page's element: the roles read the family where they are
defined.

```css
/* A platform's theme */
:root { --gv-font-family-document: 'Source Serif 4', Georgia, serif; }
```
