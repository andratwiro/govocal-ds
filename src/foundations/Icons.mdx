# Icons

Lucide icons, named as in Figma; the full set is at [lucide.dev](https://lucide.dev).

export const figmaNames = iconsJson.figma;
export const hasLucide = name => Boolean(lucide[toPascalCase(name)]);
export const inFigma = figmaNames.filter(hasLucide);
export const noMatch = figmaNames.filter(name => !hasLucide(name));
export const prototypeOnly = ['map-pin', 'map', 'layout-grid', 'eye-off', 'grip-vertical', 'calendar', 'clock',
  'globe', 'flag', 'lock', 'message-circle', 'megaphone', 'thumbs-up', 'trash-2', 'pencil', 'external-link',
  'panel-left-close', 'panel-left-open'];
export const codeOnly = iconsInUse.used.filter(name => !figmaNames.includes(name) && !prototypeOnly.includes(name));
export const IconPair = ({name}) => {
  const Icon = lucide[toPascalCase(name)];
  return <>
    <Icon size={16} strokeWidth={1.75} aria-hidden="true" />
    <span style={{marginInlineStart: 8}}><Icon size={20} strokeWidth={1.75} aria-hidden="true" /></span>
  </>;
};

## In Figma

Named on the Figma `Icons` page, with a `lucide-react` match.

<IconGallery>
  {inFigma.map(name => (
    <IconItem key={name} name={name}><IconPair name={name} /></IconItem>
  ))}
</IconGallery>

## Drawn in Figma, no Lucide match

Named on the Figma `Icons` page, but `lucide-react` has nothing by that name yet — rename or replace in Figma.

<IconGallery>
  {noMatch.map(name => (
    <IconItem key={name} name={name}><lucide.CircleDashed size={16} aria-hidden="true" style={{opacity: 0.35}} /></IconItem>
  ))}
</IconGallery>

## Not in Figma

The [prototype](https://govocal.augur.page/ux-ui-audit/design/?theme=0) already draws these; Figma doesn't name them yet.

<IconGallery>

  ))}

## In the code, not in Figma

The components and the back office import these; Figma doesn't name them yet. `npm run icons:in-use` refreshes the list.
