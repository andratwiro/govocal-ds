# Colour

**In Figma:** the `Tokens` collection, groups `surface/`, `text/`, `icon/`, `border/` and `chart/`, drawn on the
Foundations page's Color frame; the primitives are the `Primitives` collection, hidden from publishing. `npm run
tokens:pull` reads them; tokens Figma has no variable for yet are written by hand (**Not in Figma**, below).

Every colour a component paints is a semantic token, named by one grammar:

```
--gv-{property}-{role}[-strong][-{state}]
```

`surface-danger` is the danger tint, `surface-danger-strong` the solid danger fill, `surface-danger-pressed` the tint
held down; `text-link-hovered` a link under the pointer. Right-click a row of a table to see which components use it.

  "| emphasis | none (a surface: the tint) · `strong` (the solid fill) |",

].join('\n')}</Markdown>

A semantic name holds no hue (`red`, `teal`: those are primitives), no component (`button`, `toast`: only the side
nav has its own tier) and no Go Vocal word (`live`, `reviewed`). Two tokens of one property that look the same keep
apart only when their jobs differ, and their descriptions say which to pick.

## Not in Figma

Tokens the components need that Figma has no variable for yet, written by hand in `tokens/semantic.tokens.json`
(danger, warning, success, selected, inverse and their states). When Figma gains one, it leaves that file. The focus
ring, opacity and layers are on **Focus and states**.

<NotInFigma />

## Renamed

What `npm run tokens:rename` moved, from `tokens/renames.json`. There are no aliases: an old name fails the build
(`tests/tokens-defined.test.mjs` names its replacement). **Figma follows** says whether the Figma variable has the new
name yet.
