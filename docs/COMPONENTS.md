# Components index

Generated by `npm run components:index` from the stories; never edit by hand. One line per Storybook entry:
name, export, what it is for, its stories (each story is a configuration to copy). Search it before drawing UI;
then open that entry's stories file for the usage. Import paths and props: docs/API.md. "Not for" (from the
part's `<Name>.guide.md`) names the part to use instead.

## Components / Actions
- **Button** `Button`: A button that does something on this page: save, create, confirm, open a menu. Stories: All States, Primary, Secondary, Sizes, With Menu, Disabled, Quiet, Danger, Quiet Danger, Pending, Icon Plus Text Vs Icon Only, Keyboard, Long German Labels, Arabic.
  - Not for: To go to another page, a section or a file: use **Link**. A button never navigates. For an icon with no words (a pencil, a ×, a "…"): use **Icon button**. For a small action inside a card or a panel section, such as "Explore" in a dashboard card's foot: use **Compact button**. To pick one of two to five views or options: use **Segmented control**. To turn a setting on or off: use **Switch**. For a list of actions on one thing: use **Menu** (opened from a Button with a menu, or a row's "…").
- **Compact button** `CompactButton`: A small 32-tall button for an action inside a card, a panel section or a dashboard card's foot ("Explore", "Add", "Import", "+ Add a report"): React Aria's B… Stories: All Variants, Secondary, Primary, Primary Icon, Disabled, Keyboard.
  - Not for: For the main actions of a page, a dialog or a panel ("Save", "Create project"): use **Button**. For an icon with no words in a card's head: use **Icon button** (or Card's `iconActions`). To go to another page: use **Link**. For a list of actions on one thing: use **Menu**.
- **Icon button** `IconButton`: A square button with an icon and no words, named by its `aria-label`: settings, a download, ‹ ›, a row's move up and down, a panel toggle. Stories: All Variants, Ghost Default, Ghost Strong, Bordered Strong, Small, Disabled, Keyboard.

For a row's several actions: one "…" that opens a **Menu**, not a row of icons.
